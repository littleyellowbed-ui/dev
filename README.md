# AI 숏폼 수익화 클래스

HTML, CSS, JavaScript로 만든 반응형 모집 랜딩페이지입니다.

## 실행

별도 빌드 없이 `index.html`을 브라우저로 열거나 정적 파일 서버로 실행합니다.

```bash
python -m http.server 8000 --directory site
```
